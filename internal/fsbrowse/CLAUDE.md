# internal/fsbrowse

Everything about touching the local filesystem on the frontend's behalf lives here. This whole package exists because the tool's core feature (save the SRT next to the source video) requires an absolute local path, and a browser's native file picker/drag-and-drop will never hand one back — so instead the server browses the disk itself and the frontend just renders what it returns.

- `ListDrives()` — enumerates drive letters via `windows.GetLogicalDrives`/`GetDriveType`, skipping `DRIVE_NO_ROOT_DIR`/`DRIVE_UNKNOWN`.
- `List(dir)` — lists `dir`'s subdirectories and video files only (everything else filtered out; see `videoExtensions`/`IsVideoFile`), directories first then alphabetical, case-insensitive. It's a thin wrapper: `ListFiltered(dir, IsVideoFile, "video")`. Expects `dir` to already be absolute/cleaned — validate with `ValidateAbsDir` first, neither function re-checks.
- `ListFiltered(dir, match, fileType)` — the general form `List` wraps. `httpapi`'s browse handler calls this directly for the Settings panel's file pickers: `ListFiltered(dir, IsExeFile, "file")` when browsing for ffmpeg.exe/whisper-cli.exe, and `ListFiltered(dir, func(string) bool { return false }, "")` for a directories-only listing when picking the models directory override (there's nothing to click *within* the directory in that case).
- `ValidateAbsDir` / `ValidateVideoFile` / `ValidateExeFile` — the normalization boundary for any path arriving from the client. `ValidateVideoFile`/`ValidateExeFile` are both thin wrappers around the unexported `validateFile(p, match, what)`. All three run `filepath.Clean(filepath.FromSlash(p))` before validating, because free-typed fields (custom output directory, and now the Settings panel's path inputs) can contain forward slashes. Every HTTP handler that receives a path from the request should go through one of these, not `os.Stat` directly.
- `EnsureWritable(path)` — opens (creating if absent, never truncating existing content) then immediately closes `path`, used to fail a job submission fast if the target `.srt` is locked by something (e.g. a media player has it open). **Treat any non-nil error as "not writable"** — don't pattern-match `os.ErrPermission` specifically. Windows reports a locked file as a sharing violation, which is a different error than access-denied, so a narrow check would silently miss the single most common real-world case this function exists to catch.
- `CopyFile(src, dst)` — opens `src` and copies it into `dst` (creating or truncating), used by `httpapi`'s job-export handler to duplicate an already-finished job's `.srt` into a user-chosen folder on demand. This is a separate, additive action from the automatic write whisper-cli already does at job completion — `CopyFile` never touches `src`.

Tests use `t.TempDir()` real-filesystem fixtures throughout, no mocking — see `fsbrowse_test.go` for the pattern if you add more path-handling functions here.
